1. Project Overview

A complete AI-powered voice calling platform that enables businesses to make and receive phone calls using artificial intelligence. The AI agent speaks naturally, follows custom scripts/prompts, handles multilingual conversations, and provides real-time transcripts, call recordings, and analytics.

2. Scope of Work

Core Platform Features

  • AI Voice Pipeline: Voice Activity Detection → Speech-to-Text → AI Brain → Text-to-Speech
  • Outbound Calling: AI dials phone numbers and follows custom conversation scripts
  • Inbound Calling: AI answers incoming calls with configured persona
  • Bulk Dialer: Campaign-based multi-number calling with queue management
  • Multilingual Support: Hindi, English, Tamil, Telugu, Bengali, Marathi + auto-detection
  • Real-time Transcripts: Live conversation text during and after calls
  • Call Recordings: Automatic recording with cloud storage and download
  • Custom Prompts: Client-configurable AI scripts per campaign

Dashboard & Admin

  • User Dashboard: Call history, stats, transcript viewer, prompt management
  • Admin Panel: User management, subscription control, system monitoring
  • Authentication: Email-based signup/login with email verification
  • Subscription & Payments: Razorpay integration with plan management

Technical Infrastructure

  • Multi-provider AI: Swappable LLM (OpenAI/Groq), STT & TTS (Sarvam AI), Voice Cloning (Sarvam AI)
  • SIP Telephony: PSTN integration for real phone calls (Indian numbers supported)
  • WebRTC Media: LiveKit Cloud for real-time audio streaming
  • Cloud Deployment: Production-ready hosting with auto-scaling
  • Database: PostgreSQL with user data, call logs, transcripts
  • WhatsApp Notifications: Post-call summary messages
