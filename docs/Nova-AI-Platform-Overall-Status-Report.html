1. Core Platform — What's Built & Working

Authentication & Onboarding

Sign-up / Sign-inDone
Email/password auth via Supabase (frontend/src/app/login/page.tsx); sign-up collects name & phone and upserts user_profiles, then requires email confirmation.
Route ProtectionDone
Dashboard/admin pages and key API routes are gated by frontend/src/middleware.ts; separate admin login screen at /admin/login.

Dashboard & Analytics

Stats, Charts & Date FiltersDone
DashboardStats.tsx shows call totals/rates/charts; DashboardDateFilter.tsx provides date-range selection, all backed by a live stats API.
Disposition & Cost BreakdownDone
AnalyticsBreakdown.tsx reports call dispositions and per-agent/per-campaign performance, with an estimated cost figure based on a rate-per-minute.
AI Analytics AssistantDone
Chat-style Q&A over the user's own call logs (AnalyticsAssistant.tsx + /api/analytics-assistant), with persisted chat threads.

Calling

Single Call DispatcherDone
CallDispatcher.tsx → /api/dispatch validates the phone number, checks subscription quota, creates a LiveKit room with call metadata, and logs the call.
Bulk Dialer CampaignsDone
BulkDialer.tsx supports phone lists, file uploads, saved scripts, per-contact personalization and Google Sheet import; /api/queue dispatches up to 100 contacts per request with quota checks.
Call History & TranscriptsDone
CallHistory.tsx, TranscriptHistory.tsx and LiveTranscript.tsx provide recordings, searchable transcripts and a Supabase-realtime live transcript view during active calls.

AI Agents & Knowledge Base

Agent BuilderDone
AgentBuilder.tsx supports templates, language/voice selection, versioning, duplication, archiving and in-app testing (AgentTestWidget.tsx) via /api/agents and its sub-routes.
Knowledge Base (RAG)Done
KnowledgeBaseManager.tsx ingests files/URLs/pasted text, chunks and embeds them (capped at 300 chunks/document); backend/agent.py retrieves relevant chunks at call time via the match_knowledge_chunks RPC.

Integrations

Outbound WebhooksDone
Customers register webhook URLs (WebhooksManager.tsx); HMAC-signed deliveries fire on call.completed / call.no_answer, with a delivery-history view.
API KeysDone
ApiKeysManager.tsx issues/revokes keys through /api/api-keys; the raw key is shown once on creation and only a prefix is stored/listed afterward.
WhatsApp NotificationsDone
Post-call WhatsApp message sent via Wampli from the LiveKit webhook handler, gated by the WHATSAPP_ENABLED flag and configured credentials.
Google Sheets Read/WriteDone
Public sheets can be imported as a contact list (up to 2,000 rows); googleSheetsWrite.ts writes call outcomes back to the matching row via a Google service account.

Billing, Admin & Backend Core

Subscriptions & PaymentDone
Razorpay Checkout integration (UpgradePlan.tsx → /api/payment → /api/payment/verify) creates orders, verifies the HMAC signature, and activates Basic/Pro/Enterprise plans.
Admin PanelDone
/admin exposes user and subscription management via /api/admin/users and /api/admin/subscriptions, aggregating usage/call stats across all accounts.
Voice PipelineDone
backend/agent.py runs the LiveKit voice loop: Silero VAD, Deepgram Nova-2 STT, Groq (default) or OpenAI LLM, and Cartesia (default; Deepgram/OpenAI/Sarvam/ElevenLabs also supported) TTS.
Telephony — Vobiz SIPDone
Outbound SIP trunking, call dispatch APIs, event webhooks, recording and transcripts are all live. Remaining telephony work (DTMF, native Vobiz webhooks, number provisioning, sub-accounts) is tracked in the separate Vobiz Integration Status Report and summarized in Section 5.

3. Built, But Needs Hardening Before Production Scale

Hardcoded Admin AccessNeeds Hardening
Admin authorization is a single hardcoded email (admin@gmail.com) in middleware.ts, not a role-based model — fine for now, but won't scale to multiple admins.
Silent Fetch/Write FailuresNeeds Hardening
CallHistory.tsx and dashboard stats polling swallow fetch errors silently; /api/dispatch doesn't verify the subscription-update or phone-log insert succeeded before reporting success to the user.
Bulk Dialer Is Client-DrivenNeeds Hardening
Campaign pacing/continuation is handled in the browser, not a durable server-side job queue — closing the tab or losing connection can interrupt an in-progress bulk campaign.
Hardcoded Business ValuesNeeds Hardening
Plan pricing/quotas are hardcoded in the payment routes (₹999/₹2,999/₹9,999); DEFAULT_TRANSFER_NUMBER in backend/config.py is a hardcoded placeholder number; login-page stats ("500+ Calls Made", "98% Uptime") are hardcoded marketing copy, not live metrics.
No Payment Webhook ReconciliationNeeds Hardening
Subscription activation relies on the client calling /api/payment/verify after checkout; there's no server-side Razorpay webhook to reconcile payments that succeed but never reach that call.
WhatsApp Template Is FixedNeeds Hardening
Every call outcome currently sends the same event-reminder WhatsApp template with a fixed Zoom link, rather than an outcome-specific message — looks like a leftover from a one-off campaign.
